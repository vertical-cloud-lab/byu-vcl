# Atomizer installation and training: videos, SOP, and compilations

Work in progress (issue #124). Synthesis of the AMAZEMET rePowder install and training videos on the BYU VCL
YouTube channel into an operating procedure, a timestamp log, keyframes, step visualizations and narrated tutorials.

- [`timestamps.md`](timestamps.md) — every substantive moment in the 26 videos, with non-autoplay YouTube links
- [`notes/`](notes/) — per-video indexes (summary, timestamp log, procedural steps, parameters, quotes, open questions)
- [`transcripts/`](transcripts/) — YouTube auto-captions (`autosubs/`) and Whisper large-v3-turbo transcripts (`whisper/`)
- [`keyframes/`](keyframes/) — contact sheets (scene changes + one frame every 2 min) per video
- [`tools/`](tools/) — the scripts that produced all of the above
