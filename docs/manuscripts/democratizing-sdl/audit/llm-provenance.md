## What counts as the inputs and outputs

- **Inputs:** the trigger comments linked above, which are public. Each session also read the repository and public web resources. The audit reports list every query whose result is reported, including those that found nothing.
- **Outputs:** the response comments, the commits on the branch `claude/issue-188-20260828-1557` (PR #193) and `claude/issue-188-20260826-1925` (PR #190), and the reports in this folder.
- **Not retained:** full step-by-step transcripts of the August–October sessions. The Actions logs record the model usage and the final result, not the tool calls, and they expire after 90 days. `claude.yml` began keeping encrypted execution logs as run artefacts on 2026-11-25 (repository PR #395), after those sessions.
