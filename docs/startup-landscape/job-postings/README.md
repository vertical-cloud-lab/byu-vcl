# Job postings: the actual roles and descriptions

*Work in progress: the archived (Wayback) half is still being fetched; this note will carry the findings.*

Every posting recovered for the surveyed companies, with its full description where one survives. Current postings come from each company's public job-board API, and past postings from Wayback Machine captures of the same boards. Each company has a page listing its postings by first-seen date, with the role-specific part of each description underneath. The cross-company tables are in [summary.md](summary.md), and the full text is in [`../data/job_postings.jsonl`](../data/job_postings.jsonl).
