[`SOP/sem-eds-polishing-sop.md`](../SOP/sem-eds-polishing-sop.md) it covers.

Compiled 2026-09-25 by scanning all issue and pull-request comments across the 20
`vertical-cloud-lab` repositories (428 YouTube mentions, 211 distinct video IDs) and
cross-referencing them against the public listings of the lab's YouTube channels.

Most of these live in **[#77](https://github.com/vertical-cloud-lab/byu-vcl/issues/77)**,
not in [#110](https://github.com/vertical-cloud-lab/byu-vcl/issues/110), which is why they
are easy to miss when reading the SOP thread.

## Method, so this can be redone

- **No YouTube API access.** `YT_API_KEY` is still unprovisioned (`CLAUDE.md` says so, and
  it is absent from the workflow env), so there is no channel-manager view and unlisted
  videos cannot be enumerated from the channel side.
- **Public listing works from a CI runner.** `yt-dlp --flat-playlist` against
  `/videos`, `/shorts` and `/streams` returns the full listing. Only *player* extraction is
  bot-blocked from datacenter IPs — see the `CLAUDE.md` note about running that half from
  the stream-cam Pi.
- **Unlisted videos are detectable without any credential.** YouTube's oEmbed endpoint
  (`https://www.youtube.com/oembed?format=json&url=…`) returns title and channel for
  unlisted videos, and 403/404s for private or deleted ones. A video ID that oEmbed
  resolves to a VCL channel but that appears in none of the three public tabs is unlisted.
- **Source of the links.** `gh api --paginate` over `repos/{owner}/{repo}/issues`,
  `.../issues/comments` and `.../pulls/comments` for all 20 org repos, regex-matched for
  `youtu.be/`, `youtube.com/watch`, `/shorts/`, `/embed/`, `/live/` and `/playlist`.
